# Judelyn Ycot Reparial Student Portfolio

A complete, responsive student portfolio built with HTML5, CSS3, and vanilla JavaScript.

## Project Structure

- `index.html` - Main portfolio page
- `css/style.css` - Portfolio styles
- `js/script.js` - Menu, navigation, and back-to-top behavior
- `assets/images/` - Profile and portfolio images
- `projects/smartquiz/` - SmartQuiz application
- `projects/gradetrack/` - GradeTrack application

## Run Locally

1. Open the `Judelyn-Portfolio` folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

You can also open `index.html` directly in a modern browser.
